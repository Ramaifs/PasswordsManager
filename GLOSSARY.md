# Менеджер паролей

Термины хранения и управления учётными данными пользователя.

## Термины

**Хранилище**:
Совокупность сохранённых пользователем записей об учётных данных.

**Запись**:
Сведения об одной учётной записи сервиса: название, адрес сайта, логин, почта, телефон, пароль, категория и заметка. Логин, почта и телефон — отдельные поля; несколько аккаунтов одного сервиса представлены разными записями.
_Избегать_: Аккаунт пользователя менеджера — это другое понятие.

**Категория**:
Именованная группа записей внутри личного хранилища. У записи одна категория; «Без категории» обозначает отсутствие пользовательской категории.

**Мастер-пароль**:
Основной секрет пользователя для разблокировки хранилища.
_Избегать_: Пароль Google, пароль отдельной записи.

**Ключ восстановления**:
Отдельный секрет пользователя для восстановления доступа к хранилищу при утрате мастер-пароля.
_Избегать_: Резервная копия хранилища — она сохраняет данные, но сама по себе не заменяет секрет для доступа.

**Локальная рабочая копия**:
Сохранённое на компьютере пользователя состояние хранилища, доступное для работы без подключения к интернету.

**Синхронизация**:
Согласование изменений хранилища между компьютерами пользователя через его Google Drive.
_Избегать_: Резервное копирование — оно сохраняет возможность вернуться к прежним данным.

**Конфликт записи**:
Несовместимые изменения одной записи, для которых сохраняются варианты, требующие выбора пользователя.

**Резервная копия**:
Отдельно сохранённое состояние хранилища для восстановления данных при их утрате или повреждении.
_Избегать_: Ключ восстановления — он восстанавливает доступ, а не утраченные данные.

**Корзина**:
Часть хранилища с удалёнными записями, которые ещё доступны для восстановления или окончательного удаления.

**Подключение Google**:
Разрешённый пользователем доступ приложения к его Google Drive для синхронизации хранилища.
_Избегать_: Разблокировка хранилища — она требует собственного секрета пользователя.

**Восстановление доступа**:
Возвращение возможности разблокировать сохранившееся хранилище при утрате мастер-пароля.
_Избегать_: Восстановление данных — оно возвращает утраченное или прежнее содержимое.

**Восстановление данных**:
Возвращение содержимого хранилища из ранее сохранённой копии.
_Избегать_: Восстановление доступа — оно само по себе не возвращает утраченный файл.

**Черновик записи**:
Незавершённые изменения записи, которые ещё не подтверждены действием «Сохранить». Сохранённый черновик доступен только на текущем компьютере и не участвует в синхронизации.

**Облачная версия**:
Отдельно опубликованное зашифрованное состояние хранилища, участвующее в синхронизации. Необработанная или конфликтующая версия сохраняется до разрешения ситуации.
_Избегать_: Единственная резервная копия — версии могут представлять ещё не объединённые изменения.
