# Argon2id и AES-256-GCM через cryptography

Для получения ключа из мастер-пароля выбран Argon2id, для шифрования с проверкой целостности — AES-256-GCM из `cryptography` (Q41). Шифруются все поля записей, категории, корзина и черновики. Это заменяет открытый JSON исходной программы и задаёт основу совместимости формата; вариант шифрования только пароля не отвечает согласованной защите содержимого хранилища.

Мастер-пароль: 8–128 символов, включая пробелы и кириллицу, без обязательного сочетания классов и календарной смены (Q42). Конкретные параметры KDF, структура защиты ключа данных через мастер-пароль и восстановление, уникальность nonce и версия формата документируются и проверяются до использования настоящих данных. Указанные алгоритмы не заменяют проверку протокола и реализации.

Источники: [cryptography KDF](https://cryptography.io/en/stable/hazmat/primitives/key-derivation-functions/), [cryptography AEAD](https://cryptography.io/en/stable/hazmat/primitives/aead/), [RFC 9106](https://www.rfc-editor.org/rfc/rfc9106.html), [NIST SP 800-63B](https://pages.nist.gov/800-63-4/sp800-63b.html). Рекомендации NIST использованы как ориентир политики ввода, без заявления о сертификации локального хранилища.
