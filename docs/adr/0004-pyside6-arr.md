# PySide6 и All Rights Reserved для собственного кода

Собственный код приложения распространяется на условиях All Rights Reserved. Для интерфейса используется PySide6. Это сохраняет настольный интерфейс Qt и допускает закрытое распространение собственного кода при соблюдении LGPL выбранных библиотек. Вариант PyQt потребовал бы коммерческой лицензии для распространения под условиями, несовместимыми с GPL; вместо него выбран PySide6 с подходящими LGPL-компонентами Qt.

Решение заменяет [0001](0001-pyqt-desktop-interface.md). ARR распространяется на собственный код, а права на сторонние компоненты определяются их лицензиями. Условия использования описаны в [лицензии](../../LICENSE.txt), состав сторонних компонентов — в [уведомлениях](../../THIRD_PARTY_NOTICES.md).
