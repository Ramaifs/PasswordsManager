# PySide6 и All Rights Reserved для собственного кода

Пользователь выбрал All Rights Reserved для собственного кода приложения и согласовал замену PyQt на PySide6. Это сохраняет настольный интерфейс Qt и допускает закрытое распространение собственного кода при соблюдении LGPL выбранных библиотек. Вариант PyQt потребовал бы коммерческой лицензии для распространения под условиями, несовместимыми с GPL; вместо него выбран PySide6 с подходящими LGPL-компонентами Qt.

Решение заменяет [0001](0001-pyqt-desktop-interface.md). ARR распространяется на собственный код, а права на сторонние компоненты определяются их лицензиями. Конкретные условия использования приложения, права на исходный репозиторий, лицензии зависимостей и состав поставки ещё требуют проверки; файл лицензии приложения пока не оформлен.

Источники: [Riverbank License FAQ](https://www.riverbankcomputing.com/commercial/license-faq), [лицензии Qt for Python](https://doc.qt.io/qtforpython-6/licenses.html), [обязательства Qt LGPL](https://www.qt.io/development/open-source-lgpl-obligations).
