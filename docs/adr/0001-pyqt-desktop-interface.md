# Основной интерфейс — настольное приложение на PyQt

Статус: заменено решением [0004 — PySide6 и ARR для собственного кода](0004-pyside6-arr.md). Исторический выбор PyQt сохранён ниже.

В исходном плане предусматривался веб-интерфейс; при обсуждении пользователь выбрал настольное приложение на PyQt. Опубликованный сайт имеет второстепенный приоритет. Поэтому основной пользовательский интерфейс проектируется для настольного приложения; возможная веб-версия потребует отдельного решения. Конкретная версия PyQt, поддерживаемые ОС и способ распространения пока не выбраны.
