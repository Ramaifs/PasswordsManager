# Аварийная замена ключа восстановления меняет ключ данных

Пользователь может заподозрить, что ключ восстановления стал известен постороннему. При его замене создаётся новый ключ восстановления, меняется ключ шифрования данных и заново шифруется актуальное хранилище; остальные компьютеры должны повторно разблокировать хранилище и обновить доступ. Простая замена отображаемого ключа без изменения ключа данных не отвечает выбранному сценарию компрометации. Ранее скачанные посторонним копии остаются вне действия этой операции.

Это отдельная операция от обычной смены мастер-пароля, при которой ключ восстановления сохраняется.

Защита восьми управляемых резервных копий обновляется под актуальные данные доступа; вручную экспортированные файлы не изменяются, о возможной необходимости прежних секретов пользователь уведомляется перед операцией. Несинхронизированные изменения устройств со старым доступом сохраняются отдельно и переносятся только после разблокировки обеих версий и подтверждения. Одновременная замена ключей сохраняет обе версии до явного разрешения конфликта. Схема обмена отдельными версиями описана в [0007](0007-drive-versions.md); детальный протокол безопасного завершения операций требует реализации и проверок.
