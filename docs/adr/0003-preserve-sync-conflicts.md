# Конфликты записей требуют выбора пользователя

Пользователь может изменить одну запись на нескольких компьютерах без интернета. Изменения разных записей объединяются автоматически, а конфликтующие версии одной записи сохраняются до выбора пользователя. Автоматический выбор по времени изменения отвергнут, поскольку он мог бы скрыть нужную пользователю версию пароля. Одновременные удаление и редактирование одной записи также считаются конфликтом. Хранение отдельных облачных версий описано в [0007](0007-drive-versions.md); формат, распространение удалений и безопасность конкурентного обмена подлежат реализации и проверкам.
