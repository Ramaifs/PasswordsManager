# Подготовка другого домена

Дата: 2026-10-25. После согласия пользователя выбран перенос на Cloudflare Pages (`pages.dev`), без покупки личного домена. Текущий Sites-проект приватный и остаётся доступным.

Подготовлен отдельный [пакет загрузки](../artifacts/cloudflare-pages-upload.zip), [проверяемый манифест](../artifacts/cloudflare-pages-preparation.json) и [порядок переноса](../deployment/cloudflare-pages/README.md). Текущий веб-код и его размещение не менялись. Пакет содержит только проверенные assets плюс заголовки Cloudflare/лицензию; папка `.openai` не переносится.

Фактический перенос **не выполнен**: нет доступа к Cloudflare-аккаунту через подключение, CLI или credentials окружения. API подключения Sites умеет привязать уже принадлежащий пользователю домен, но не выдаёт поддомен другого провайдера. Существующий `chatgpt.site` не переименовывался в вымышленный `pages.dev`.

Для завершения требуется реальная авторизация Cloudflare, создание проекта, приватный Access для production и preview, публикация и проверка фактического URL. Настройка только preview не делает основную страницу приватной. Перед сменой origin пользователь должен экспортировать хранилища: его IndexedDB не переносится средствами хостинга.
