# Перенос сайта на Cloudflare

Статическое приложение можно разместить на Cloudflare Workers или Pages. Подготовка ZIP и порядок проверки описаны в [инструкции размещения](../deployment/cloudflare-pages/README.md). Для существующего Worker см. [состояние переноса](cloudflare-worker-status.md).

Перед сменой адреса экспортируйте нужные хранилища в `.pmvault`, затем откройте их на новом сайте. Данные браузера привязаны к origin и не переносятся автоматически. До проверки открытия, сохранения и экспорта сохраните исходные копии.
