# Версия 0.38

- Цвета категорий и подкатегорий передаются через Google Drive между Windows и сайтом. Ранее выбранные цвета включаются при следующей синхронизации; выбирать их заново не нужно. Для обмена цветами обновите Windows-клиенты до 0.38. Старые версии не поддерживают новые метаданные и могут остановить обмен до обновления.
- Windows запоминает обычный, развёрнутый и полноэкранный режим окна между запусками и при возврате из трея, в том числе после минимизации.
- Числовые поля настроек получили отступ слева. Кнопки закрытия имеют контуры; «В трей» выделена и выбрана по Enter, «Закрыть» завершает работу. При недоступном трее окно не скрывается.
- Добавлены значки разделов по образцу сайта, переключатель темы, первая буква названия в значке записи и разделитель «Категории».
- Настройки и тема сайта больше не вызывают скачивание импортированного файла. Явный экспорт сохранён.
- Обмен OAuth на Cloudflare использует поддерживаемый режим redirect: manual без пересылки секретов по перенаправлениям. Ошибки Google и этапов сессии отображаются без раскрытия данных провайдера.

Windows-файлы: `releases/0.38/PasswordsManager.exe`, `releases/0.38/PasswordManager-0.38-portable.zip`. ZIP сайта `releases/0.38/PasswordManager-web-0.38.zip` создаётся только локально; на GitHub публикуются два Windows-файла.

Проверки и ограничения: [протокол 0.38](verification-0.38.md).
