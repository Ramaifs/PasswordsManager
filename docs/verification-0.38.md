# Проверка 0.38

Проверки выполняются на вымышленных хранилищах. Python/Qt, Chromium с имитацией Drive, упакованный EXE и live HTTP являются отдельными уровнями доказательств.

## Windows

Проверяются три режима окна, минимизация, возврат из трея и повторный запуск; Enter/default в диалоге закрытия, отсутствие трея, независимое сохранение настроек, числовые отступы, значки и переключение темы. Снимки светлой/тёмной темы и диалогов: `artifacts/ui-038`.

## Сайт

Регрессионный сценарий сначала воспроизвёл скачивание файла при сохранении настроек после импорта без file handle. После исправления настройки и тема не вызывают скачивание, явный экспорт работает. Имитатор Drive возвращает modifiedTime, чтобы выбор последней копии соответствовал данным настоящего API.

## Google OAuth

Live POST с заведомо недействительным кодом сначала возвращал общий HTTP 502. Диагностика из фиксированных кодов локализовала несовместимый режим redirect: error в fetch Cloudflare. После замены на manual запрос дошёл до Google, который отклонил Client secret. После обновления секрета контрольный запрос возвращает HTTP 401 oauth_invalid_grant: недействительный код отклонён, пара Web Client ID/secret принята.

Полные ошибки провайдера, коды авторизации, токены и секреты не сохраняются. KV/шифрование сессии проверяются локальными тестами. Реальный вход на сайте и сохранение подключения после перезагрузки подтверждены при ручной проверке 2026-10-26. Это не означает приёмки всего обмена с реальным Drive на нескольких устройствах.

## Результаты

- 118 Python-тестов, включая 33 проверки GUI/preferences; зависимости и 128 локальных Markdown-ссылок проверены.
- 29 Node-тестов; 47 сценариев Chromium с вымышленными данными и имитацией Drive.
- Визуально проверены светлая/тёмная темы, отступы настроек, значки и диалог закрытия.
- Сайт 0.38 развёрнут в Worker `3eaec4a2-a931-47f2-9d1a-daf70f872226`. SHA-256 опубликованных index.html, app.js, google.js и storage.js совпадает с исходниками (`artifacts/cloudflare-public-check.json`).

PyInstaller завершился с кодом 0. Проверочный запуск упакованного EXE выполнен без администратора, с PATH только System32 и зависимостями из поставки; offscreen smoke пройден. QtSvg включён в замыкание зависимостей сборки для отрисовки значков. Установка поверх рабочего приложения и испытание на чистой Windows в этот прогон не входят.
