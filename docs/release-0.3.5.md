# 0.3.5: подкатегории, настройки приложения и обновления

Подкатегории доступны в Windows и на сайте. У каждой категории может быть один
родитель. В списке видна вложенность, а в выборе категории записи — путь.
Выбор родителя показывает записи всей его ветки. Удаление категории сохраняет
её подкатегории на уровень выше; собственные записи удалённой категории остаются
без категории. Пустые поля записей в просмотре по-прежнему скрываются.

В Windows нажмите ПКМ на категорию: создание новой категории или подкатегории,
переименование, выбор цвета и удаление. ПКМ по пустому месту позволяет создать
корневую категорию. Внизу слева оставлена кнопка настроек. Импорт JSON, экспорт,
резервные копии, конфликты и объединение файла доступны в настройках. Нижние
кнопки блокировки и отдельного генератора убраны; блокировка остаётся сверху,
генератор — в редакторе пароля. Настройки прокручиваются в небольшом окне.

## Совместимость и синхронизация

Иерархия хранится в `category_parents` отдельно от названий и ID категорий.
Старые локальные хранилища без этого поля читаются как плоские. Новые отношения
синхронизируются причинными регистрами `category_parent:<uuid>`; названия,
записи и удаление продолжают использовать существующий протокол шифрования.
Обновите обе стороны обмена до 0.3.5: старые клиенты не понимают новый тип
регистра и остановят обмен вместо перезаписи неподдерживаемого состояния.

Если независимые изменения создадут цикл, участники этого цикла показываются
как корневые категории. Исходные варианты сохраняются в причинном состоянии;
имена, записи и подкатегории не удаляются. Удалённые/отсутствующие родители
также не скрывают сохранившуюся категорию. Конфликты отношения родителя
сохраняются до явного выбора, как конфликты названий и записей.
Цвета, тема, расписание и настройка обновлений остаются локальными настройками.

## Обновления и публичный код

Приложение проверяет `https://api.github.com/repos/Ramaifs/PasswordsManager/releases/latest`
в отдельном потоке после разблокировки, один раз за запуск. Проверку можно
отключить или выполнить вручную в настройках. Сравниваются числовые компоненты
стабильных версий; черновики и предварительные релизы не предлагаются.
Сетевой запрос содержит номер приложения, но не содержит данных хранилища,
Google-токенов, мастер-пароля или GitHub-токена.

При наличии новой версии предлагается открыть её страницу в браузере.
Загрузка и установка выполняются пользователем. Проверка не устанавливает и
не исполняет файлы из репозитория автоматически. Источник API:
[GitHub Releases](https://docs.github.com/en/rest/releases/releases#get-the-latest-release).

Собственный код — **All Rights Reserved**, условия в `LICENSE.txt`. Публичный
доступ к исходникам не означает выдачу открытой лицензии. Лицензии сторонних
компонентов приведены отдельно в `THIRD_PARTY_NOTICES.md` и в поставке.
Пользовательские хранилища, токены, окружение Python, выходы сборки и локальный
Desktop OAuth JSON исключены из Git. Обычная сборка без этого JSON поддерживается:
для подключения Google потребуется предоставить Desktop OAuth JSON в приложении.
Разработчик может положить свой JSON в `src/password_manager/google-desktop.json`
для включения в собственную поставку; этот путь игнорируется Git.

## Сборка

В подготовленном окружении из корня проекта:

```powershell
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/build.py
.\.venv\Scripts\python.exe scripts/check_bundle.py
.\.venv\Scripts\python.exe scripts/package_windows.py
```

В `releases/0.3.5` находятся установщик `PasswordsManager.exe`, portable ZIP,
веб-архив и manifest.json с контрольными суммами. Установщик предназначен для
текущего пользователя и сохраняет прежнее хранилище AppData. Portable использует
собственную папку `data`. Базовые сборки предыдущих версий сохранены отдельно.
Сайт снаружи не обновляется публикацией исходников или веб-архива.

## Проверки и границы

Python: 97 тестов; Node: 19 тестов, в том числе обмен иерархией Python/JS,
наследование фильтра, сохранение подкатегорий при удалении, защита от циклов,
сравнение версий и отказ от недоверенного URL обновления. API для тестов
обновления подменяется локальной фикстурой. Проверки реального Google Drive,
установки/удаления в пользовательский профиль и чистой VM не выполнялись.
