# Версия 0.41

- «Кастомизация» в настройках: системная, светлая или тёмная тема и основной цвет интерфейса. По умолчанию — фиолетовый, `#8864cb`.
- «Прочие пароли» обозначены `*`, исключены из «Без категории». Кнопка вставки создаёт отдельную запись для каждой непустой строки буфера, сохраняя пробелы внутри пароля.
- «Продвинутые настройки» расположены справа от «Показать пароль». Кнопки «+» добавляют нумерованные почту, пароль, телефон, логин, сайт и второй пароль (2FA).
- При создании записи 2FA скрыт до включения продвинутых настроек. В существующей записи с дополнительными данными раздел раскрывается автоматически. Единая галочка показывает и скрывает все пароли записи.
- Поле «Старые пароли» убрано. При открытии хранилища его содержимое переносится в «Пароль №2» целиком, включая пробелы, знаки и переносы строк. Уже существующие дополнительные пароли сохраняются. Миграция включает черновики и корзину; исторические копии и причинные версии синхронизации не переписываются.
- Установщик `PasswordsManager.exe` позволяет ввести папку установки или выбрать её через «Обзор…». По умолчанию предлагает прежнюю папку установки, если она известна. Хранилище остаётся в AppData.
- В Windows-приложении «Проверить обновления» открывает выбор опубликованной стабильной версии GitHub. Установщик скачивается в приложение с индикатором прогресса, отменой, ограничением размера и проверкой SHA-256 из манифеста. После загрузки доступна кнопка «Установить». Для версии 0.41 и новее установщик дожидается закрытия приложения.

Windows x64: `PasswordsManager.exe` — установщик; `PasswordManager-0.41-portable.zip` — переносимая версия. `manifest.json` содержит размеры и SHA-256 файлов для проверки загрузки из приложения. В portable-версии запускайте `PasswordManager.exe` вместе с каталогом `_internal`.

Сайт: https://password-manager-vault.masaoyhs.workers.dev. Веб-версия обновлена до 0.41; все 23 публичных файла сверены с локальной сборкой по SHA-256. Веб-архив сохраняется локально и не входит в файлы GitHub Releases.

Для данных с дополнительными полями используйте Windows-приложение и сайт версии 0.41 или новее. Предыдущие версии могут отклонять новые поля. Загрузка старой версии требует отдельного подтверждения.

Проверки и границы: [протокол 0.41](verification-0.41.md).
