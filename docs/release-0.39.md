# Версия 0.39

- Копии Google Drive идут от новых к старым по времени, независимо от типа файла.
- Самая свежая копия последнего открытого хранилища закреплена сверху под подписью «Последнее открытое хранилище». Остальные копии отсортированы по времени без дублирования закреплённой.
- Сайт сохраняет UUID последнего успешного открытия между перезагрузками.
- Windows показывает все облачные копии до и после разблокировки: просмотр, экспорт .pmvault, переключение рабочего хранилища.
- Перед переключением прежнее хранилище и все локальные резервные состояния сохраняются в отдельный проверенный зашифрованный архив. Архив можно открыть из приложения.
- В репозитории добавлен ARCHITECTURE.md: карта модулей, хранение, шифрование, синхронизация, Google OAuth, сайт и поставка.

Установщик: `PasswordsManager.exe`. Переносимая версия: `PasswordManager-0.39-portable.zip`. ZIP сайта `PasswordManager-web-0.39.zip` создаётся локально и не публикуется в GitHub Releases.

Проверки: [протокол 0.39](verification-0.39.md).
