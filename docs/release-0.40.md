# Версия 0.40

- Автоподстановка текущей категории или подкатегории при создании записи.
- Сортировка записей по алфавиту и последнему изменению с сохранением выбора.
- Перемещение категорий и подкатегорий вместе с дочерними ветками через перетаскивание и меню Windows; защита от циклов.
- Зашифрованные поля «Второй пароль (2FA)» и «Старые пароли», скрытые по умолчанию, с показом и копированием.
- Поиск по всем текстовым полям. Телефон находится без учёта пробелов, скобок и дефисов, в том числе в заметке.
- Раздел «Прочие пароли» с двумя полями: пароль и заметка.
- Локальная автоподстановка почты, телефона, логина и сайта из активных записей открытого хранилища.

Старые хранилища и история синхронизации читаются без преобразования причинных версий. Для записей с новыми полями и типом используйте актуальные Windows-приложение и сайт.

Windows x64: установщик `PasswordsManager.exe` и переносимый архив `PasswordManager-0.40-portable.zip`. В переносимой версии запускайте `PasswordManager.exe` вместе с каталогом `_internal`.

Сайт: https://password-manager-vault.masaoyhs.workers.dev. Веб-архив создаётся локально и не входит в GitHub Releases.

Проверки: 173 Python-теста, 40 Node-тестов, 59 браузерных сценариев на вымышленных данных, frozen smoke и аудит упаковки. Подробности: [протокол 0.40](https://github.com/Ramaifs/PasswordsManager/blob/v0.40/docs/verification-0.40.md).
