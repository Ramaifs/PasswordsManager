# Веб-версия

Статическое приложение на JavaScript с русским интерфейсом. Исходники и команды запуска находятся в [web/password-manager](../web/password-manager/README.md).

Хранилище сохраняется в файл `.pmvault` на ПК или Google Drive. Новые хранилища не записываются в постоянную базу браузера; история, черновики и очередь обмена находятся в памяти вкладки. Перед закрытием сохраните изменения в файл или завершите синхронизацию. Старые браузерные копии можно экспортировать и удалить отдельно.

Формат PMVAULT v1 совместим с Windows: Argon2id через локальный `hash-wasm`, AES-256-GCM через Web Crypto, отдельный ключ восстановления. Мастер-пароль содержит 8–128 символов. Поддерживаются записи, поиск, категории, генератор, корзина, темы, блокировка по бездействию и явное разрешение конфликтов.

Google подключается через GIS OAuth с разрешением `drive.file`. Токен существует только в памяти до истечения, отключения или перезагрузки. Блокировка удаляет ключ расшифрования и отменяет запросы, сохраняя действующее подключение Google. Сохранение записи и синхронизация выполняются отдельно.

## Проверки и ограничения

Node-тесты проверяют криптографию, совместимость Python/JavaScript, очередь, конфликты, расписание и ошибки Drive. Браузерные сценарии выполняются в изолированном Qt Chromium на вымышленных данных с имитацией Google API и файловых handles. Они не подтверждают реальную авторизацию Google, нативный выбор файла, разрешения буфера обмена или работу опубликованного сайта. Независимый аудит безопасности не проводился.

Код хостинга, расширения и операционная система могут получить доступ к вводу и памяти приложения. Автоматическая очистка буфера зависит от разрешений браузера. Зашифрованные экспорты следует хранить отдельно.
