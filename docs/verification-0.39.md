# Проверка 0.39

Все автоматические проверки используют собственные вымышленные данные. Настоящие пользовательские хранилища не переключаются и не экспортируются во время проверки.

## Облачные копии

Проверяются общий порядок по времени для полных снимков и версий синхронизации, временные зоны, резервная дата из имени, неизвестное время, закрепление свежей копии последнего хранилища и отсутствие её дубликата в общем списке. Список Windows не ограничивается текущим UUID хранилища. Перед чтением проверяются размер/целостность и совпадение UUID выбранного файла.

## Последнее открытие

Windows сохраняет UUID в preferences.json независимо от режима окна и закрытия. Сайт хранит только UUID в localStorage, обновляет его после успешного открытия и восстанавливает после перезагрузки. Браузерный сценарий проверяет, что неверный пароль и выбор файла без разблокировки не меняют маркер.

## Просмотр и переключение

Проверяются скрытый пароль и явное раскрытие, экспорт выбранной копии с последующей расшифровкой, неизменность рабочего хранилища при просмотре/отмене, переключение на другой ключ и сохранение прежних байтов в архиве. Ошибка записи архива и ошибка публикации нового поколения оставляют прежний CURRENT действующим. Просмотр подчиняется блокировке и таймеру бездействия.

Сборка Windows, frozen smoke, браузерный интерфейс, имитация Drive, развёртывание сайта и проверка реальных устройств учитываются отдельно. Итоговые отчёты находятся в artifacts и releases/0.39. Установка поверх рабочей программы и живое переключение пользовательского Drive автоматически не выполняются.

## Итоговые результаты

- 134 Python-теста и 32 Node-теста пройдены.
- 52 сценария Chromium пройдены: в том числе реальная перезагрузка страницы с сохранённым UUID и список копий на узком экране.
- PyInstaller завершился с кодом 0. Собранный EXE прошёл offscreen smoke без администратора с зависимостями из поставки.
- Проверены локальные ссылки документации, включая карту архитектуры. Снимки нового интерфейса находятся в `artifacts/ui-039` и `web/password-manager/artifacts/browser`.
- Опубликованные файлы сайта сверяются с текущими исходниками по SHA-256 в `artifacts/cloudflare-public-check.json`; архивы и ресурсы EXE проверяются в `artifacts/release-0.39-audit.json`.
