## Генератор

[HardPassGenerator.py](https://github.com/Ramaifs/Passwords-Manager/blob/eab2103453ddca4e3dadf2998130bddca544eb76/HardPassGenerator.py) — консольный скрипт с `random`, JSON, статистикой и `pyperclip`. Настраивает длину, количество и алфавиты, сохраняет настройки, копирует результат.

Проблемы: случайный Unicode-сдвиг выводит результат за пределы выбранного набора; границы `randrange` исключают последние элементы; исходные и восстановленные настройки различаются; нулевая и отрицательная длина не отклоняются. Для новой версии алгоритм заменяется.

Настройки: `%LOCALAPPDATA%\Ramaif Programs\HardPassGenerator\data.json`:

```json
{"All": ["alphabet"], "PasswordLen": 20, "RepeatPassword": 1}
```

Значения выше иллюстративные; реальные настройки пользователя не читались.

## Менеджер

[PasswordManager.py](https://github.com/Ramaifs/Passwords-Manager/blob/eab2103453ddca4e3dadf2998130bddca544eb76/PasswordManager.py) — отдельный консольный скрипт. `match` требует Python 3.10+. Открытые данные сохраняются в `%LOCALAPPDATA%\Ramaif Programs\PasswordManager\data.json`.

Схема: название платформы → список объектов со строками `Username`, `Email`, `Phone`, `Password`. Пример содержит только вымышленные данные:

```json
{
  "Example Service": [
    {
      "Username": "demo-user",
      "Email": "demo@example.invalid",
      "Phone": "+00000000000",
      "Password": "Fictional-example-only"
    }
  ]
}
```

Частично реализованы создание платформы, добавление позиции аккаунта, ввод Username и автоматическое сохранение этих действий. Ввод остальных полей и Password не завершён. Поиск, редактирование, ручное сохранение и импорт/экспорт содержат заглушки; удаления нет.

Обнаружены загрузка только заранее существующих ключей `System.data`, совместное использование `System.construct` без копирования, ошибочная обработка текстового выбора платформы и печать загруженного объекта. Генератор не интегрирован; шифрования, мастер-пароля, GUI, Drive, 2FA и ключа восстановления нет.

Схема используется как основание нового импортера с раздельным сохранением логина, почты и телефона. Исходный пользовательский файл не должен изменяться.

## README и ограничения проверки

[README.md](https://github.com/Ramaifs/Passwords-Manager/blob/eab2103453ddca4e3dadf2998130bddca544eb76/README.md) описывает локальную beta и будущие веб-интерфейс, Drive и возможную 2FA. Эти планы не подтверждают реализацию.

Ранние попытки прямого доступа к GitHub не удавались; позднее исходники стали доступны через connector. Старые записи CHANGELOG о недоступности относятся к моменту тех проверок. Исходники локально не клонировались, зависимости не устанавливались и код не запускался. Права на использование и перелицензирование исходного кода отдельно не подтверждены.
