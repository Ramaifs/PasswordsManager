ADDED:

- Автономный APK с локальным зашифрованным хранилищем, карточками категорий, поиском и отдельным редактором.
- При открытии хранилища и возврате в приложение предлагается применить обнаруженные изменения Google Drive.
- Отдельное красное окно «Удаление/Отключение» для облачных версий, локального сохранения и приложения.

CHANGED:

- Для Android в релизе доступен только APK.
