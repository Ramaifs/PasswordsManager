# Версия 0.42

Исправление Android Google Drive: добавлено отсутствовавшее разрешение INTERNET.
Без него подтверждение доступа в браузере проходило, а APK не мог завершить
подключение. APK versionCode 44 имеет прежнюю подпись автономной версии 0.42
и устанавливается поверх неё с сохранением данных.

- Windows: зелёное сообщение «Синхронизация выполнена!», «Отключить Google Drive».
- Категория настроек «Удаление/Отключение» открывает отдельное окно: облачные
  версии, локальное сохранение, приложение. Ниже категории в основных настройках
  доступны проверка обновлений и автоматическая проверка при запуске. Удаление требует подтверждения. Облачное удаление убрано из обычных
  Google-действий. Локальная очистка сохраняет настройки и внешние экспорты.
- Видимая галочка использует PNG, доступный в собранном приложении без SVG-плагина.
- Колесо изменяет число только после клика по полю, до потери фокуса.
- При разблокировке и возврате проверяются облачные изменения. Перед применением
  появляется предложение; отказ не запускает фоновое применение. Слияние сохраняет
  конфликтующие варианты и локальные изменения.
- Исправления обновления Google-токена и резервной проверки релиза при лимите GitHub.
- Android: автономный APK с локальным зашифрованным сохранением и интерфейсом по
  референсу Apple Passwords. Карточки реальных разделов и категорий, счётчики, поиск
  внизу и отдельный редактор. Google Drive нужен только для обмена. Прежняя отдельная
  Native-реализация удалена; сайт не обновлялся.

Android APK имеет новую подпись. Перед удалением старого APK сохраните данные в
Drive или экспортируйте .pmvault; затем установите 0.42 и откройте сохранённую копию.
Сборка и проверки не означают проверку установки и Google-входа на телефоне.
