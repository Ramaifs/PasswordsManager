Мобильное дополнение хранится отдельным последующим коммитом main.

На сайте для Android/iOS используется переход на официальный Google OAuth
endpoint с `state`, PKCE S256, offline access. Начало требует same-origin POST
с CSRF-заголовком. Callback до отдачи HTML проверяет шифрованный HttpOnly
cookie и срок; код обменивается только сервером и убирается из URL до загрузки
страницы. Refresh token остаётся в зашифрованном KV. Открытое хранилище сохраняет
свою вкладку в памяти, пока авторизация идёт в отдельной вкладке. На ПК сохранена
GIS popup-схема и добавлена кнопка альтернативного входа.

Перед изменением Google отклонял новый URI `https://password-manager-vault.masaoyhs.workers.dev/`
с `redirect_uri_mismatch`. Пользователь добавил URI в Google Cloud; повторный
прямой запрос Google, включая URL с PKCE от развёрнутого Worker, больше не содержит
`redirect_uri_mismatch` или `invalid_request`. Это проверка начала потока,
не подтверждение успешного входа реального аккаунта на телефоне. Исходная
страница Google 400 на устройстве пользователя локально не воспроизведена;
мобильная popup-схема заменена альтернативным потоком с проверенными параметрами.
