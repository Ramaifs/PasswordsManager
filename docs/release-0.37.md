# Версия 0.37

- Иконка замка с сайта используется в заголовке окна, панели задач, EXE, установщике и ярлыке меню «Пуск». Для поиска Windows и установленного приложения нужно обновить программу установщиком этой версии.
- Категорию можно перетащить в другую категорию: она станет её подкатегорией вместе со всей своей веткой. Перенос на «Все записи» возвращает ветку на верхний уровень. Записи сохраняют привязку к прежним категориям. Перенос в себя или в собственную дочернюю ветку запрещён.
- Правая стрелка сворачивает и раскрывает подкатегории. Вместо `>` используется `•`. В Windows также работают клавиши влево и вправо. Изменения доступны в Windows и веб-версии.
- При закрытии Windows-приложения предлагаются «В трей», «Полностью» и «Отмена». Галочка «Не спрашивать больше» сохраняет выбранное действие. Изменить его можно в настройках, в разделе «Общие» → «При закрытии окна».
- Закрытие в трей блокирует хранилище. Значок замка рядом с часами открывает приложение; в меню трея доступны «Открыть», «Заблокировать», «Выйти». При недоступном системном трее окно не скрывается.
- Добавлена [пошаговая инструкция Cloudflare Worker для Windows](../deployment/cloudflare-worker/README.md).

Windows-сборки: `releases/0.37/PasswordsManager.exe` и `releases/0.37/PasswordManager-0.37-portable.zip`. Архив сайта `releases/0.37/PasswordManager-web-0.37.zip` создаётся отдельно, только локально; на GitHub публикуются два Windows-файла. Статический ZIP не включает серверную часть Google-сессий — она размещается через конфигурацию Worker.

Проверки включают перенос и сворачивание категорий, сохранение выбора закрытия, отмену закрытия, блокировку при уходе в трей, исходную и упакованную иконку, браузерные сценарии и проверочный запуск EXE. Иконки EXE и установщика проверяются по содержимому Windows-ресурсов. Установка поверх существующего приложения, выдача результата через поиск Windows и реальная настройка Cloudflare проверяются отдельно.
