# Password Manager для Android · 0.41

Устанавливаемый APK — клиент веб-версии через системный браузер (Custom Tabs с
обычным HTTPS-браузером как fallback). Это не перенос PySide6 и не самостоятельное
офлайн-хранилище. Для загрузки сайта нужен интернет. Google-вход не открывается
во встроенном WebView. Все операции с хранилищем выполняет тот же веб-клиент,
что и на сайте: PMVAULT, локальное шифрование, Google Drive, импорт и экспорт.
Подключение Google принадлежит профилю выбранного браузера.

APK: `releases/0.41/PasswordManager-0.41-android.apk`.
Требуется Android 6.0+ (API 23) и браузер с актуальными Web Crypto, WebAssembly,
JavaScript modules и HTML dialog. Сам API 23 не гарантирует поддержку старым браузером.
Сборка использует имеющийся SDK platform 32 / build-tools 32.0.0.

Скачайте APK на телефон и откройте его. Android может запросить разрешение
установки из данного источника. После установки откройте Password Manager.
Перед закрытием браузера сохраните изменения в Google Drive или `.pmvault`:
сайт держит новые хранилища только в памяти вкладки. Android-клиент не добавляет
скрытого локального хранения. На iOS используется сайт в Safari; APK на iOS
не устанавливается.

## Сборка

Из корня проекта, с уже установленными Python-зависимостями, JDK и Android SDK:

```powershell
.venv\Scripts\python.exe scripts/build_android.py --sdk <SDK> --jdk <JDK>
```

Скрипт ничего не скачивает и не устанавливает. Он компилирует Java, создаёт DEX,
упаковывает ресурсы, выравнивает ZIP, подписывает APK и проверяет подписи v1/v2/v3.
Отчёт с SHA-256, публичным сертификатом и хешами исходников:
`releases/0.41/android-manifest.json`.

Для следующих обновлений сохраняйте одну и ту же подпись:
`deployment/android-signing/release.keystore` и `password.dpapi`. Оба файла
исключены из Git и выпусков. Пароль защищён Windows DPAPI и открывается только
под текущим Windows-пользователем. Для переноса среды сборки потребуется безопасно
перенести ключ и отдельно восстановить пароль до удаления старого профиля Windows.
Потеря ключа означает невозможность обновить уже установленный APK с той же подписью.

## Мобильный Google-вход

В Web OAuth-клиенте должен быть разрешён точный redirect URI:
`https://password-manager-vault.masaoyhs.workers.dev/`.
На Android/iOS сайт использует полный переход Google с PKCE и привязанным к
браузеру state. При открытом хранилище используется отдельная вкладка, чтобы
не потерять данные в памяти исходной вкладки. Исходная вкладка получает сессию
через свой серверный маршрут; секреты не передаются через URL или postMessage.

Документация платформ: [Google OAuth web-server](https://developers.google.com/identity/protocols/oauth2/web-server),
[Custom Tabs без AndroidX](https://developer.chrome.com/docs/android/custom-tabs/guide-get-started).

Сборка и подпись проверены на Windows. Проверка установки на физическом Android,
реальный вход на Android/iOS и поведение конкретных браузеров требуют отдельной
приёмки на устройствах.
