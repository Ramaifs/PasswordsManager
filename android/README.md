# Password Manager Android 0.42

Автономный APK для Android 8.0+. Интерфейс, Argon2id, AES-GCM и работа с PMVAULT
встроены в приложение. Сайт для запуска, поиска, создания и редактирования не нужен.
Интерфейс использует локальный Android WebView с закрытым HTTPS-адресом ресурсов;
внешние страницы в него не загружаются. Это отдельный интерфейс для APK, опубликованный
сайт сохранён прежним.

После разблокировки: карточки разделов со счётчиками, пользовательские категории,
поиск внизу, список записей и отдельный редактор. Сохраняются дополнительные поля,
генератор, корзина, черновики и зашифрованная история. Сохранение происходит атомарно
в приватной папке приложения, только в зашифрованном виде. Доступен экспорт .pmvault
через системный выбор файла. Android backup и снимки экрана отключены.

Google Drive используется только для обмена. Согласие открывается в системном
браузере, сессия хранится под защитой Android Keystore. Ключи хранилища остаются в
локальном шифрующем Worker. OAuth использует уже существующие /api/android/ маршруты,
привязку к случайному verifier и отдельную сессию. При открытии и возврате проверяются
изменения других устройств; перед применением появляется предложение.

APK 0.42 подписан доступным текущему Windows-профилю ключом, отличным от старого
браузерного APK 0.41. Перед удалением старого приложения экспортируйте .pmvault или
синхронизируйте Drive. Старый ключ и его DPAPI-файл сохранены.

Сборка без скачивания зависимостей:

    python scripts/build_android.py --replacement-key

Публиковать только releases/0.42/PasswordManager-0.42-android.apk. Отчёты, хеши,
сертификат и служебная подпись v4 остаются локально в artifacts/.

Проверено: компиляция Java/DEX, подпись APK, автономный упакованный интерфейс в
изолированном Chromium с имитацией Android-моста, реальная криптография, сохранение
и повторное открытие после перезагрузки. Телефон по ADB не подключён. Работа Android
WebView, Keystore, системного импорта/экспорта и реальный Google-вход требуют проверки
на устройстве; успешные локальные проверки этого не подтверждают.
