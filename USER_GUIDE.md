# Менеджер паролей 0.41 — инструкция

## Копии Google Drive

На сайте откройте «Google Drive — Действия» → «Все копии Google Drive». В Windows кнопка «Все копии Google Drive» есть на экране блокировки и в настройках; она также доступна через меню действий Google Drive.

Новые копии показаны первыми по времени сохранения, независимо от того, являются они полным снимком или версией синхронизации. Самая свежая копия последнего открытого хранилища закрепляется отдельно сверху под заголовком «Последнее открытое хранилище». Остальные копии продолжают идти по времени. Для старых файлов без временных метаданных используется время из имени; при отсутствии обеих дат копия находится в конце списка.

Сайт запоминает UUID последнего успешно открытого хранилища между перезагрузками. Выбор файла и ошибка мастер-пароля этот маркер не меняют. Для открытия данных после перезагрузки снова выберите копию в Drive и введите её мастер-пароль.

В Windows нажмите «Открыть», введите мастер-пароль выбранной копии и просмотрите записи. Пароли скрыты до установки галочки. «Экспорт .pmvault» сохраняет самостоятельный зашифрованный файл. «Переключиться на эту копию» делает выбранные данные рабочим хранилищем после подтверждения.

Перед переключением все прежние локальные состояния сохраняются в `switched-vaults/<UUID>` внутри каталога данных и проверяются побайтово. Архив можно открыть кнопкой «Архив прежних хранилищ» на экране блокировки или в настройках. Для старого архива нужен его прежний мастер-пароль. Переключение само по себе не публикует новую версию в Drive.

## Запуск и данные

Для установки запустите `releases/0.39/PasswordsManager.exe`. Программа устанавливается для текущего пользователя в `%LOCALAPPDATA%\Programs\PersonalPasswordManager`, появляется в меню «Пуск», поиске Windows и списке установленных приложений. Права администратора не нужны. Удаление приложения сохраняет хранилище паролей.

Для portable-режима распакуйте `PasswordManager-0.39-portable.zip` и запустите `PasswordManager.exe`. Сохраняйте `_internal` и `portable.flag` рядом с EXE. Данные записываются в папку `data` рядом с программой. Папка должна быть доступна для записи. Python не требуется. Программа не добавляет автозапуск, службу или расширения браузера.

Установленная версия использует `%LOCALAPPDATA%\PersonalPasswordManager`, отдельно от программы, включая прежнее хранилище версий до 0.3.4. Portable-версия использует собственную папку `data`. Для переноса используйте зашифрованный экспорт или вход в тот же Google Drive. Одновременно каталог данных открывает один экземпляр программы. Подключение Google защищено DPAPI и требует повторного входа при переносе portable на другой компьютер.

Для обновления закройте приложение и запустите PasswordsManager.exe. Прежние данные AppData откроются автоматически. Для перехода на portable сначала сохраните зашифрованный экспорт и откройте его в portable-версии. Перенос данных автоматически не выполняется.

## Интерфейс

В версии 0.35 категории могут содержать подкатегории. Выбор родительской категории включает записи всех дочерних веток. При удалении родителя подкатегории поднимаются на уровень выше, записи удалённой категории сохраняются без категории.

В приложении управление категориями открывается по ПКМ на категории; ПКМ по пустому месту создаёт новую корневую категорию. Настройки находятся снизу слева. Импорт, экспорт, резервные копии, конфликты и объединение файла перенесены в настройки. Для генерации пароля используйте кнопку в редакторе записи. Блокировка находится справа сверху.

В настройках доступна проверка обновлений GitHub и галочка автоматической проверки после разблокировки. Кнопка «Проверить обновления» открывает список опубликованных стабильных версий с установщиком и манифестом. Выберите версию, нажмите «Скачать», дождитесь проверки SHA-256 и нажмите «Установить». Приложение закроется и откроет установщик. Переходить в браузер и искать файл в «Загрузках» не требуется. Собственный код проекта сохраняет лицензию All Rights Reserved.

Слева — категории, подкатегории и корзина. Управление категорией открывается по ПКМ. В средней колонке находятся поиск и «Новая запись», справа — редактор. В небольшом окне редактор прокручивается.

«Настройки» открывают тему, автоматическую блокировку, Google Drive, импорт, экспорт, резервные копии, конфликты и объединение файла. Верхняя кнопка «Заблокировать» скрывает записи и возвращает экран мастер-пароля.

В настройках галочка автоматической синхронизации находится справа от надписи. Ниже задаётся интервал (по умолчанию 5 минут) и находится «Синхронизировать сейчас». Снятая галочка включает ручной режим. Кнопка сохранения настроек находится внизу. При обмене справа внизу появляются «Синхронизация..» и «Синхронизация выполнена!»; при ошибке показывается её описание.

Существующие записи открываются для просмотра: видны только заполненные поля и назначенная категория. Пустые строки и неназначенная категория скрываются. В режиме редактирования показываются все поля. Для изменения нажмите «Редактировать», затем «Сохранить». Просмотр позволяет показать и скопировать пароль. Верхняя кнопка блокировки доступна и без выбранной записи.

Для удаления или изменения цвета категории на сайте нажмите значок настроек рядом с ней. В Windows эти действия доступны по ПКМ на категории. При удалении записи сохраняются без категории. По умолчанию цвет фиолетовый. Цвета категорий и подкатегорий сохраняются в зашифрованном хранилище, экспорте и синхронизации Google Drive. Ранее выбранные локальные цвета включаются при следующем обмене без повторного выбора. При одновременном выборе разных цветов на двух устройствах разрешите конфликт в Google Drive → «Конфликты».

Войти в Google можно в настройках без выбора технического JSON. На новом профиле кнопка «Войти через Google Drive» позволяет загрузить существующее хранилище; потребуется его мастер-пароль. Вход Google не заменяет мастер-пароль. Реальная авторизация зависит от настроек и тестовой аудитории Google-проекта.

## Создание и восстановление

Введите мастер-пароль из 8–128 символов и повторите его. Поддерживаются пробелы и кириллица; пароль не обрезается и не изменяется. Сохраните показанный ключ восстановления отдельно и подтвердите сохранение. В окне выдачи ключа есть явное сохранение в выбранный файл вне каталога хранилища. Это открытый секрет: не отправляйте его в общую папку или вместе с экспортом.

Если мастер-пароль утрачен, выберите «Восстановить доступ по ключу». При первоначальной настройке другого компьютера доступно «Восстановить доступ из файла»: нужны зашифрованный файл и соответствующий ключ. Без обоих секретов серверного восстановления нет.

В версии 0.36 имя хранилища задаётся при создании и меняется в настройках. Экспорт имеет имя `<имя>-vault-export.pmvault`. В «Все записи» название окрашено в цвет категории, ниже показана её подпись. Тема и автоблокировка находятся вверху настроек; блок Google Drive содержит действия, цветной статус и кнопку синхронизации.

## Записи, генератор и корзина

Создайте запись, заполните необходимые поля и нажмите «Сохранить». Название обязательно; остальные поля необязательны. Совпадающие названия разрешены. Пароль скрыт, пока вы явно не включите показ. Поиск учитывает название, сайт, логин, почту и заметку. При создании записи автоматически выбирается текущая категория или подкатегория; её можно изменить перед сохранением. В общих разделах выбирается «Без категории». Удаление категории сохраняет её записи без категории, а дочерние категории переносит на уровень выше.

Под поиском выберите сортировку: «По алфавиту (А–Я)» или «По изменению (сначала новые)». Выбор сохраняется на устройстве и действует также на результаты поиска и корзину. Переключение сортировки сохраняет открытый редактор и несохранённые правки.

Поиск проверяет все текстовые поля записи, включая телефон и поля паролей. Можно вводить часть значения без учёта регистра. Номер `+7 (999) 123-45-67` находится по `+7999`, `9991234567` и номеру с другим оформлением; это работает и для номера в заметке. Результаты ограничены выбранным разделом или категорией.

В полях почты, телефона, логина и сайта при вводе предлагаются значения из активных записей открытого хранилища. Выберите подходящее, чтобы не печатать его заново. Подсказки не берутся из корзины и не сохраняются отдельно от хранилища; после блокировки они очищаются.

Раздел «Прочие пароли» предназначен для паролей без учётной записи: нажмите «Новая запись», укажите пароль и при необходимости заметку. Другие поля не показываются. Подпись в списке берётся из первой строки заметки; без заметки используется «Пароль». Такие записи также видны во «Всех записях», участвуют в поиске, шифровании и синхронизации. Прежние обычные записи автоматически в этот раздел не переносятся.

Внизу записи справа включите «Продвинутые настройки»: появится 2FA и кнопки «+» у почты, пароля, телефона, логина, сайта и 2FA. Дополнительные поля нумеруются, например «Пароль №2». При создании 2FA скрыт; заполненные дополнительные данные раскрываются при открытии существующей записи. Одна галочка «Показать пароль» показывает и скрывает все пароли записи. Это постоянные пароли сервиса; генерация одноразовых кодов не выполняется. Все дополнительные поля шифруются вместе с записью и локальными черновиками.

Отдельного поля «Старые пароли» больше нет. При открытии хранилища прежнее значение целиком переносится в дополнительный пароль №2. Пунктуация и переносы строк не разбивают его на новые пароли, чтобы сохранить исходное значение. Старые резервные копии сохраняются в исходном виде.

Старые хранилища открываются без заполнения новых полей. После сохранения записей с новыми полями используйте обновлённые Windows-приложение и сайт: прежние сборки могут отклонить неизвестные поля.

Генератор позволяет выбрать длину 8–128, группы символов, исключение похожих символов и количество до 100. В редактор можно вставить первый результат. Генерация и её настройки не записываются в хранилище и не синхронизируются с Google; настройки запоминаются в памяти текущего запуска. Пароль попадёт в обмен только после сохранения самой записи.

Удаление помещает запись в корзину на 30 дней. В корзине доступны восстановление и окончательное удаление. Прежние резервные копии могут содержать удалённые данные; они не выдаются за стёртые с накопителя.

«Очистить корзину» удаляет все записи в ней после подтверждения, независимо от
текущего поиска. Активные записи не затрагиваются. Старые резервные копии и
ручные экспорты при очистке не переписываются.

Через 30 минут бездействия, при блокировке Windows или сне приложение должно блокироваться; интервал можно менять в настройках. Незавершённый ввод сохраняется в зашифрованный локальный черновик. Если запись на диск невозможна, приложение скрывает данные и предупреждает об утрате черновика. При перезапуске приложение заблокировано. Черновики, тема и настройки автоблокировки не отправляются в Drive; цвета категорий участвуют в обмене.

Копирование пароля выполняется кнопкой. Через пять минут приложение очищает текущий буфер, если он всё ещё содержит скопированный пароль. Новое содержимое не удаляется. История Windows и сторонние менеджеры буфера этим не очищаются.

## Импорт, экспорт и резервные состояния

«Импорт JSON» читает прежнюю схему «название платформы → список аккаунтов». Поля `Username`, `Email`, `Phone`, `Password` сохраняются раздельно. До записи показан предпросмотр. Неверные типы, неизвестные поля и повторяющиеся JSON-ключи отклоняются целиком. Источник не изменяется. Пример `examples/legacy-demo.json` содержит только вымышленные данные.

«Экспорт» создаёт новый зашифрованный `.pmvault`; открытого экспорта паролей нет. При первом запуске на другом компьютере выберите «Открыть зашифрованный экспорт». Существующие независимые хранилища объединяются через «Объединить файл», после ввода секрета источника и подтверждения.

Сохраняются восемь последних успешных локальных состояний. «Резервные копии» показывает сводку различий перед восстановлением, сохраняет актуальное состояние и создаёт новое изменение. Если актуальный файл повреждён, попробуйте «Проверить резервную копию» на экране блокировки. Исходные зашифрованные файлы сохраняются в `damaged-*`.

## Google Drive

Подключение добровольное. Для этой сборки сначала нужен общий OAuth-проект разработчика: [подготовка Google](docs/google-setup.md). Кнопка Google Drive позволяет выбрать JSON Desktop app и подтвердить доступ в системном браузере. OAuth открывает доступ к Drive, а не к мастер-паролю. Токены хранятся под Windows DPAPI текущего пользователя и компьютера; их нельзя просто переносить вместе с файлом подключения.

После подключения доступна ручная синхронизация и повтор примерно раз в минуту, когда хранилище открыто и редактор не содержит несохранённого ввода. При блокировке новые сетевые операции останавливаются, результат выполняющегося запроса не применяется. Успех показывается после чтения опубликованных байтов обратно и сохранения локального подтверждения. Если сеть пропала, локальные изменения и очередь остаются на диске.

Разные записи объединяются. Для несовместимых изменений одной записи, удаления против изменения или категории сохраняются варианты. Откройте «Конфликты», просмотрите варианты и явно подтвердите нужный. Пароль варианта скрыт до отдельного действия. Обычное сохранение конфликтующей записи не заменяет этот выбор.

Если обнаружены другие ключи или другое хранилище, публикация останавливается. Зашифрованные исходники доступны в `sync-blocked`. «Объединить файл» требует разблокировать источник; для того же хранилища можно сохранить текущий доступ либо явно принять доступ выбранной версии. Разные хранилища импортируются добавлением отдельных записей. Старые исходники и экспорты не перешифровываются автоматически.

Отключение Google удаляет локальное подключение, сохраняя локальные и облачные файлы. Удаление облачных служебных версий — отдельное подтверждаемое действие, после которого Google отключается на этом компьютере. Ручные копии остаются. Другой подключённый компьютер может снова опубликовать свои данные.

Если папка Drive удалена вручную, приложение останавливает обмен. Повторная загрузка требует «Создать папку заново» и подтверждения. Это не восстанавливает облачные изменения, которые не успели попасть на компьютер.

## Ограничения текущей проверки

Автоматическая логика, имитация Drive, настоящая DPAPI и проверочный запуск EXE проверяются отдельно. Реальный OAuth/Drive, два реальных подключённых компьютера, физический сон/блокировка Windows и чистая машина без установленного Python ещё не приняты. До этой приёмки используйте вымышленные данные. Отдельная веб-версия описана в [документации сайта](docs/web.md).

Смена секретов обновляет восемь управляемых копий, но не ручные экспорты, скачанные файлы и исходники в `damaged-*`/`sync-blocked`. Обработка повреждённого `CURRENT` пока требует ручной диагностики. Подробности: [статус реализации](docs/implementation-v0.2.md).

## Категории и трей в версии 0.39

Перетащите категорию на другую, чтобы сделать её подкатегорией. Вся дочерняя ветка и привязки записей сохранятся. Для возвращения на верхний уровень перетащите категорию на «Все записи». Категорию нельзя переместить в неё саму или в её потомка.

В Windows также нажмите ПКМ по категории → «Переместить в…» и выберите назначение или «Верхний уровень». На сайте откройте настройки категории, измените «Родительская категория» и сохраните; «Без родителя» возвращает её на верхний уровень.

Стрелка справа сворачивает дочерние категории; повторное нажатие раскрывает их. Подкатегории отмечены символом `•`. В Windows также доступны клавиши влево и вправо.

При закрытии окна выберите «В трей» или «Закрыть». По Enter выбирается «В трей». Галочка «Не спрашивать больше» запоминает выбор. Его можно изменить в «Настройки» → «Общие» → «При закрытии окна», в том числе вернуть вопрос при каждом закрытии.

В трее хранилище блокируется. Значок замка рядом с часами возвращает окно; через меню значка доступны «Открыть», «Заблокировать» и «Выйти». Если значок скрыт Windows, откройте список значков стрелкой рядом с часами.

Иконка замка встроена в программу и установщик. Для обновления ярлыка и значка в поиске Windows установите новую версию. Portable-версия использует тот же значок EXE.

Окно запоминает обычный, развёрнутый или полноэкранный режим. Минимизация сохраняет предыдущий режим. При возврате из трея и следующем запуске он восстанавливается.

Кнопка с солнцем или луной внизу боковой панели переключает светлую и тёмную темы. Значки ключа, папки и корзины обозначают общие разделы; подпись «Категории» отделяет их от пользовательских категорий. Значок записи содержит первую букву её названия.

На сайте сохранение настроек и переключение темы не скачивают файл. При работе без прямого доступа к файлу изменения остаются в памяти вкладки; сохраните актуальный файл через «Экспорт» перед закрытием.


## Возможности 0.41

В настройках раздел «Кастомизация» задаёт тему и основной цвет интерфейса. Начальный цвет — фиолетовый; для его восстановления откройте «Основной цвет» и нажмите «по умолчанию» внутри окна выбора цвета, затем подтвердите выбор. Отдельной кнопки сброса в кастомизации нет. Настройки оформления относятся к текущему хранилищу.

В «Все записи» выберите «По категориям» в списке сортировки. Записи упорядочиваются по полному пути категории и подкатегории, затем по названию внутри группы; «Без категории» и «Прочие пароли» имеют отдельные названия групп. Выбор запоминается на устройстве. Длинные названия категорий сокращаются многоточием; полный путь доступен в подсказке.

«Прочие пароли» имеют значок `*` и не входят в «Без категории». Нажмите «Вставить пароли с буфера обмена», чтобы создать отдельную запись для каждой непустой строки. Пробелы в паролях сохраняются. В заметку автоматически записывается порядковый номер; следующая вставка продолжит максимальный номер активных «Прочих паролей», например после 31 начнётся с 32. Нечисловые заметки и записи корзины не определяют следующий номер.

Удерживайте Ctrl для выборочного выделения записей и Shift для диапазона от предыдущей записи до нажатой. ПКМ по выделению открывает смену цвета, категории и удаление. Индивидуальный цвет влияет только на выбранные записи; «Цвет по категории» возвращает обычную окраску. Категорию можно назначить также записи из «Прочих паролей»: она остаётся в своём разделе и дополнительно находится в выбранной категории. Удаление активных записей переносит их в корзину; окончательное удаление из корзины требует подтверждения.

В режиме редактирования удаляйте дополнительные поля кнопкой «−» справа от их названия. Удалённое значение уйдёт из текущей записи после сохранения; прежние резервные копии могут его содержать. Основные поля не удаляются. «Копировать» под основным паролем дополняет нижнюю кнопку «Копировать пароль». Все функциональные кнопки имеют контур.

Установщик `PasswordsManager.exe` позволяет выбрать папку через «Обзор…» или ввести полный путь. Для новой установки используйте пустую отдельную папку с правом записи; для обновления — папку установленного приложения. По умолчанию предлагается прежняя папка установки. Пароли остаются в `%LOCALAPPDATA%\PersonalPasswordManager`, независимо от папки программы.
