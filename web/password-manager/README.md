# Password Manager Web 0.3.1

«Очистить корзину» удаляет все записи в ней одним подтверждением, независимо от
поиска; активные записи сохраняются. Генератор работает локально и не сохраняет
хранилище, не вызывает шифрующий Worker и не обращается к Google. Его настройки
запоминаются только в памяти вкладки; пароль синхронизируется лишь после
явного сохранения записи с ним.

Создать новое или открыть существующее хранилище, затем имя, расположение,
мастер-пароль 8–128 и ключ восстановления. Оформление повторяет собственную
веб-версию, логика первого запуска вдохновлена переключателем хранилищ Obsidian.

Два места хранения: файл `.pmvault` на ПК или Google Drive. Новые зашифрованные
хранилища не записываются в IndexedDB/cookies/localStorage. Список открытых файлов,
история и резервный шифротекст существуют только в памяти вкладки. Файловый API
используется при наличии прав, иначе доступно скачивание. Прежние браузерные копии
можно экспортировать и отдельно удалить на их прежнем origin.

PMVAULT v1 совместим с Windows: Argon2id 64 МиБ/3/4, AES-256-GCM, отдельный ключ
восстановления. Есть записи, поиск, категории, генератор, корзина, зашифрованный
черновик, светлая/тёмная тема, блокировка по бездействию или вручную. Сворачивание
браузера само по себе не блокирует хранилище. Clipboard очищается только
при возможности чтения и совпадении текста.

Google Drive: GIS token model, `drive.file`, токен только в памяти до истечения,
явного отключения Google или перезагрузки. Блокировка хранилища останавливает
запросы и удаляет ключ расшифрования, сохраняя действующее подключение Google.
Публичный Web client ID задан в `dist/oauth-config.js`. Веб-клиент не получает client
secret. Только после явного подключения загружается официальная Google-библиотека.
Сохранение записи не обращается к Drive: обмен выполняется каждые 5 минут,
с настраиваемым интервалом 1–1440 минут или только вручную. Настройка находится
в общих настройках хранилища; там же доступно «Синхронизировать сейчас».
До отправки изменения находятся в памяти вкладки, статус явно показывает очередь.
Общие причинные версии совместимы с Windows; варианты конфликтов выбираются явно.
Полные зашифрованные checkpoint-копии позволяют открыть хранилище/очередь из Drive.
Сеть и превышение лимитов не выдаются за успешное сохранение. Перед закрытием
неподтверждённой сессии скачайте `.pmvault`.

Подробности и ограничения: [хранение и Drive](../../docs/web-storage-and-drive.md).
Настройка двух клиентов одного проекта: [Google OAuth](../../docs/google-setup.md).
Проект и оба OAuth-клиента созданы; реальный вход ещё не принят.

Для разработки с уже установленными зависимостями:

```powershell
npm test
npm run dev
```

`http://127.0.0.1:4173/`; для настоящего Google OAuth используйте разрешённый
`localhost` или HTTPS origin. Для Node interop-тестов требуется Python-окружение
родительского проекта. Для работы сайта Python не нужен.

16 Node-тестов: криптография, Python ↔ JS, причинный обмен, очередь/конфликты,
имитация Drive, ошибки, отмена OAuth и отсутствие записи в браузерную базу.
`scripts/browser_qa.py` проверяет интерфейс в изолированном Qt Chromium на собственных
вымышленных данных. Файловые handles и Google API в нём — fixtures; нативный picker,
реальная сеть Google и работа в опубликованном сайте требуют отдельной проверки.

`node scripts/benchmark-drive.mjs` сравнивает транспорт с зафиксированным
предыдущим Git commit на имитации из 10 файлов истории. Измеренный цикл сократился
с 53 до 19 запросов, содержимое скачивалось 12 раз вместо 43. Задержка настоящего
Google этим не измеряется. Кеш хранит только шифротекст и сверяет серверную ревизию,
а чтение опубликованных байтов обратно остаётся обязательным.
