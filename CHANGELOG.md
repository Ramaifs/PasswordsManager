# История изменений

## 2026-10-26 — 0.37

- Иконка замка для Windows-приложения, заголовка окна, панели задач, установщика и ярлыка.
- Перетаскивание категорий с сохранением веток и запретом циклов; перенос на «Все записи» возвращает категорию на верхний уровень.
- Сворачивание подкатегорий правой стрелкой и маркер `•` вместо `>`.
- Выбор закрытия в трей или полного выхода, сохранение выбора и настройка в разделе «Общие».
- Блокировка хранилища при закрытии в трей; меню открытия, блокировки и выхода.
- Пошаговая инструкция настройки Cloudflare Worker в Windows.
- Отдельный локальный ZIP сайта; в релиз GitHub входят только установщик и portable ZIP Windows.

## 2026-10-26 — 0.36

- Цветные названия записей и подписи категорий в разделе «Все записи».
- Именованные хранилища, экспорт с именем и понятные названия резервных копий Drive.
- Создание хранилища до выбора места сохранения и подключения Google.
- Удаление веб-хранилищ и отдельных облачных историй с подтверждением.
- Тема и автоблокировка перенесены вверх настроек; добавлены разделители, кнопки действий и цветной статус Google Drive.
- Google-сессии Cloudflare Worker с автоматическим продлением, защищённой cookie и шифрованием refresh token в KV.
- Windows-поставка включает установщик и portable ZIP без веб-архива.

## 2026-10-26 — 0.35

- Вложенные категории в Windows и веб-версии: создание, переименование, перемещение и удаление поддерева с сохранением записей.
- Проверка обновлений принимает версии из двух компонентов, включая `0.35`.
- Установщик и переносимый архив для Windows x64; добавлены проверки структуры поставки и версий.

## 2026-10-26 — 0.3.4

- Просмотр записи отделён от редактирования; выбор и поиск не создают изменений.
- Добавлено управление категориями, подтверждение удаления и сохранение выбора после обновления списка.
- Подготовлены установщик и переносимая сборка.

## 2026-10-25 — Windows 0.3.3 / Web 0.3.1

- Очистка всей корзины одним подтверждением независимо от фильтра поиска.
- Генератор работает в памяти и не сохраняет хранилище или данные Google Drive. Настройки сохраняются до завершения сеанса; пароль попадает в хранилище после сохранения записи.

## 2026-10-25 — Windows 0.3.2 / Web 0.3.0

- Настраиваемый интервал синхронизации: по умолчанию 5 минут, диапазон 1–1440 минут; 0 отключает автоматический обмен.
- Сохранение записи и обмен с Google Drive выполняются отдельно; добавлена ручная синхронизация.
- Убраны повторные полные загрузки. Кешируется шифротекст с проверкой серверной версии, одновременно выполняются до четырёх загрузок.
- Сохранены проверка списка, ограничения размеров, обнаружение дублей и чтение опубликованных байтов обратно.

## 2026-10-25 — Web 0.2.2

- Переключение вкладок и сворачивание браузера не блокируют хранилище до истечения таймера бездействия.
- Таймер учитывает время в фоне. Блокировка отменяет запросы и удаляет ключ расшифрования, сохраняя действующее подключение Google.
- Убран принудительный выбор аккаунта при каждом подключении.

## 2026-10-25 — Web 0.2.1

- Исправлен контекст вызова `fetch` при обращении к Google Drive.
- Добавлены регрессионный тест и браузерная проверка запроса к локальному серверу.

## 2026-10-25 — Windows 0.3.1

- Настроены Desktop и Web OAuth-клиенты одного проекта.
- В веб-версии поле Client ID заменено кнопкой подключения Google; Client secret в сайт не включается.
- Desktop OAuth поддерживает официальный legacy `auth_uri` с проверкой домена.

## 2026-10-25 — Web 0.2 / Windows 0.3.0

- Веб-хранилище сохраняется в файл на ПК или Google Drive. Старые браузерные копии доступны для экспорта и удаления.
- Добавлены GIS OAuth, транспорт Drive, очередь, разрешение конфликтов и проверка публикации обратным чтением.
- Обновлены интерфейс Windows, темы и навигация по хранилищу.
- Подготовлена сборка статического сайта для Cloudflare.

## 2026-10-25 — Web 0.1

- Создание и открытие хранилища, записи, поиск, категории, генератор, корзина и темы.
- PMVAULT v1 совместим с Windows: Argon2id, AES-256-GCM и отдельный ключ восстановления.
- Добавлены криптографические тесты и браузерные сценарии на вымышленных данных.

## 2026-10-25 — Windows 0.2.1

- Минимальная длина мастер-пароля снижена с 15 до 8 символов; максимум — 128.
- Обновлены проверка создания, смены и восстановления пароля, подсказки и тесты границ.

## 2026-10-25 — Windows 0.2.0

- Добавлены Drive v3, Desktop OAuth с PKCE и защита токенов через Windows DPAPI.
- Реализованы причинные версии, сохранение конфликтов, очередь повторной отправки и безопасная очистка истории.
- Добавлены интерфейс синхронизации, объединение хранилищ и перенос изменений после смены доступа.
- Подготовлен переносимый EXE с библиотеками, лицензиями и проверками SHA256.

## 2026-10-25 — Windows 0.1.0

- Локальное зашифрованное хранилище, генератор, записи, категории, поиск и корзина.
- Мастер-пароль, восстановление, смена ключей, восемь резервных состояний и зашифрованные черновики.
- Импорт прежнего JSON с раздельными полями логина, почты и телефона; зашифрованный экспорт.
- Русский интерфейс на PySide6, темы и автоматическая блокировка.
- Добавлены тесты криптографии, модели, прерываний записи и GUI в Qt offscreen.
